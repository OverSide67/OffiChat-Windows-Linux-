# OffiChat

Чат между ПК и Android-телефоном по Wi-Fi и Bluetooth. Текст, файлы, голос. Интернет и серверы не нужны.

**Версия 3.1.** Версия 3.1 шифрует весь трафик, поэтому она не совместима с 3.0 и более ранними версиями.

## Возможности

- Текстовые сообщения с галочками доставки и прочтения, правка и удаление у обеих сторон, индикатор «печатает…»
- Файлы до 15 МБ в обе стороны. Картинки и аудио показываются в чате
- Голосовой чат в реальном времени, приглашение с мелодией звонка
- Шифрование всего трафика по общему коду
- Никнейм, онбординг, история между запусками
- Wi-Fi (ПК и Android) и Bluetooth (Android и Linux-ПК)

## Запуск на ПК

### Windows
1. Распакуйте `OffiChat-3.1-windows-amd64.zip`.
2. Запустите `OffiChat.exe`. Откроется браузер с интерфейсом.
3. Если Windows спросит про сеть, разрешите. Иначе телефон не подключится (порт 5000).

### Linux (AppImage)
```sh
chmod +x OffiChat-3.1-x86_64.AppImage
./OffiChat-3.1-x86_64.AppImage
```
Если не запускается из-за FUSE:
```sh
./OffiChat-3.1-x86_64.AppImage --appimage-extract-and-run
```

### macOS
Откройте `OffiChat-3.1-macos_universal.pkg` и установите. Затем запустите OffiChat из «Программ». Приложение не подписано Apple, поэтому при первом запуске нажмите правой кнопкой → «Открыть». Если система всё равно блокирует, разрешите запуск в «Системные настройки → Конфиденциальность и безопасность».

### Из исходников
Нужен Go 1.22 или новее:
```sh
go run ./cmd/offichat-web
```
Откроется `http://127.0.0.1:8080`. Если порт занят: `go run ./cmd/offichat-web -addr 127.0.0.1:9000`.

## Запуск на Android

1. Установите APK.
2. При первом запуске введите никнейм и код шифрования (минимум 6 символов).
3. Выберите связь (Wi-Fi или Bluetooth) и роль: хост или клиент.
4. Нажмите «Подключиться» или «Ждать подключения».

На Xiaomi и realme разрешите приложению работу без ограничений в настройках батареи, иначе связь может обрываться в фоне.

## Код шифрования

Код шифрования должен быть **одинаковым** на ПК и на телефоне. Если кода нет или он не совпадает, соединение не открывается, и появляется сообщение «Неверный код шифрования или чужая версия приложения».

## Как соединить устройства

- **Wi-Fi.** Один телефон раздаёт точку доступа, второй или ПК подключаются к ней. Хост ждёт подключения на порту 5000. Клиент вводит IP хоста, обычно `192.168.43.1`.
- **Bluetooth.** Устройства спарены в системных настройках. На ПК Bluetooth работает только в Linux. Нужен MAC-адрес телефона и номер канала RFCOMM: `sdptool browse MAC`.

## Голосовой чат

1. Соединитесь с собеседником.
2. Нажмите «Войти в голосовой чат» и разрешите доступ к микрофону.
3. Собеседник получит приглашение и может его принять.

На ПК доступ к микрофону браузер даёт только для адреса `127.0.0.1` или `localhost`. Открывайте интерфейс по адресу из программы.

## Протокол

Строки UTF-8, каждая с переводом строки, шифруются AES-256-GCM. Ключ выводится из общего кода через PBKDF2-HMAC-SHA256. Файлы идут строкой `F|имя|base64`, голос кадрами по 20 мс (16 кГц, 16 бит, моно). Транспорт: TCP на порту 5000 или Bluetooth RFCOMM.

## Ограничения

- Bluetooth на ПК работает только в Linux.
- Одновременно поддерживается одно соединение.
- Файлы больше 15 МБ не отправляются.
- Голос работает только между двумя участниками.
- Защита от повтора сообщений не реализована: записанный трафик можно переслать повторно.
- Код шифрования хранится на устройстве: на ПК в файле настроек с правами 0600, на Android в настройках приложения.

## Где хранятся данные

- **ПК:** в каталоге настроек пользователя, `~/.config/offichat/` на Linux, `%AppData%\offichat\` на Windows, `~/Library/Application Support/offichat/` на macOS. Там лежат история, файлы и настройки.
- **Android:** внутри приложения, удаляется вместе с ним.

## Сборка

```sh
go build -trimpath -ldflags "-s -w" -o offichat ./cmd/offichat-web
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w" -o OffiChat.exe ./cmd/offichat-web
```

Для Android откройте папку `android/` в Android Studio: Build → Build APK(s).

Тесты:
```sh
go test ./... -count=1
```
